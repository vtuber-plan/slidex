# 1.7.0-rc.3 界面与文字编辑

- 文字格式面板替换右侧对象属性，使用 Portal 保留原位编辑生命周期；不在画布上方插入控件。字体、样式、颜色、内容与段落分组展示，完成和取消放在面板底部。
- 溢出提示使用覆盖层，不改变画布可用空间；双击时按点击坐标定位光标。
- 顶栏、工具区、侧栏与画布使用更明确的层级，去掉画布点阵背景。Windows 原生菜单默认收起，Alt 和快捷键继续可用，保留系统标题栏和窗口控制。
- `app/brand.svg` 是统一的折页式 S 标识；`npm run assets` 从同一矢量源生成应用图标和安装器素材。本轮仅生成 Windows x64 解压版，未发布远程。

## 验证

生产构建通过。工作区专项验证 980/1440 像素窗口中进入文字编辑前后画布坐标和尺寸完全一致，右侧格式面板无横向溢出；同时覆盖分隔条、记忆尺寸、文件打开与取消。文本专项 36 项和嵌套组合专项 18 项通过，覆盖格式选区、组合输入、链接、公式、保存重载和 Viewer 一致性。

启动：`release/1.7.0-rc.3/win-unpacked/SlideX.exe`。旧版本目录保持不动。此前完整回归的超时记录见 `release-1.7.0-rc.2.md`；本轮不将专项结果表述为完整回归全通过。

Electron 主进程专项通过，验证菜单默认隐藏、打开文件、取消与标题更新。运行测试时应清除外部环境的 `ELECTRON_RUN_AS_NODE`，否则 Electron 会以 Node 模式启动。运行时下载遇到超时，本次打包通过 `--config.electronDist=node_modules/electron/dist` 复用本机已验证的运行时。

实际解压程序通过 `test/release-package.mjs ... --ui-only`：等待初始适应画布完成后，进入文字编辑不改变画布矩形；验证侧栏挂载、Logo 加载、对象修改与保存。本轮未重复导出专项。界面预览保存在 `.qa-images/rc3-inline.png` 和 `.qa-images/rc3-narrow.png`。
