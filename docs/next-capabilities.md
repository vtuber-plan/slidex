# rc.7 后续能力规划

本轮审查基于当前源码与 rc.7 验收结果。本文仅记录 SlideX 自身的能力边界，不以功能数量推算产品成熟度百分比。前两项已在源码中实现，尚未生成新的桌面发布包；其余任务仍待推进。

## 已具备的基础

React 编辑器、原位富文本、组内编辑、多页批量操作、图层树与锁定、裁剪、表格结构编辑、图表数据面板、母版/主题、布局辅助、撤销恢复及共享 Viewer 已建立。CLI/Skill、多文件加载、静态诊断、格式化、补全、定义跳转与 LLM 图片清单已随 rc.7 分发。

## 剩余能力与证据

| 领域 | 当前边界与代码依据 | 下一步 |
| --- | --- | --- |
| 图片与填充 | 已有五种图片蒙版（含矩形）和径向渐变；背景去除仍未提供 | 蒙版预设扩展与背景去除单独评估处理方式 |
| 图表深度 | `src/ir.ts` 支持 8 类，明确拒绝第二坐标轴；`src/export/pptx-charts.ts` 原生导出仅五类基础子集 | 双轴及系列绑定、标签/刻度/堆叠；再分批加入热力、蜡烛、树图/旭日、桑基等数据协议 |
| 动画深度 | easing/repeat 已有 DSL、面板、Viewer 播放与诊断；时间线仍是查看/定位条带 | 可拖动时间线、路径控制点与更多缓动曲线 |
| 字体与输出 | 缺失字体检测和降级报告已有；尚无字体文件嵌入、全字形覆盖检查；复杂图表与动画继续回退 | 单独验证嵌入权限、子集化、Office 兼容性，避免将“可编辑”当成像素一致 |
| AI 修改闭环 | 已有按 ID 的 CLI/HTTP 增量补丁、版本前置条件、预演与原子提交；没有编辑器内对象批注和修改差异确认 | 接对象批注与人工确认/可撤销应用，不绑定外部模型服务 |
| 桌面工作流 | 文件菜单已补齐；`electron/main.ts` 记录系统最近文档，但缺少应用内最近项目页；另存已存在目标会拒绝覆盖 | 最近项目、模板入口、带明确覆盖选择的另存、查找替换和快捷键帮助 |
| Viewer | `web/Player.tsx` 支持按需渲染、内部链接、备注、演讲者同步；未有专门的触屏手势层和远程分享服务 | 先做手势、误触保护、演讲者断线重连及缩放；分享链接/权限作为独立服务能力规划 |
| DSL 工程化 | `src/language.ts` 面向传入 XML 的轻量接口；多文件编辑器呈现合并视图 | 跨文件定义/重命名、代码操作、源文件大纲及语言服务协议；逐步减少整份 XML 替换 |
| 发布与国际化 | 中文/英文已有，日语/西班牙语为部分翻译；Windows x64 实测、ARM64 静态检查；远程 CI 未核验 | 翻译覆盖检查、跨平台产物实机验收、签名与升级恢复验收 |

音视频、完整 PPTX 导入/无损往返、多人实时协作属于另立范围的能力，本轮不将其视为已有功能，也不作为当前小步迭代的前置条件。

## 推荐执行顺序

1. **图片与动画参数补齐（P1，源码已实现）**：五种图片蒙版、径向渐变、动画 easing/repeat 已有类型、诊断、面板、共享渲染和导出回退报告。自动化覆盖保存重载、嵌套对象、真实浏览器交互与导出；桌面手动播放/取消和实际 PowerPoint 外观仍需发布前实测。
2. **AI 增量编辑（P1，协议已实现）**：按 ID 操作、期望项目版本、dry-run、原子提交、冲突及变更摘要已接入 CLI/本地 API，详见 [协议](ai-patch.md)。编辑器内对象批注与人工确认/可撤销应用仍是后续工作，不绑定外部模型服务。
3. **图表与可编辑导出（P1/P2）**：先双轴和现有图表样式，再扩新数据类型；每项具备合法/非法数据样例、编辑重载和原生/回退报告。
4. **日常工作流与 Viewer（P2）**：最近项目、模板、查找替换、触屏和演讲者恢复；并完成真实发布升级及跨平台验收。

连接线锚点、路径节点、拖动式多轨动画、云端分享和协作应各自定义文档结构与撤销语义，不和上述第一批同时混入。

## 验收边界

对已有功能不重复重建。性能数据只覆盖既定样例，尚不代表 300 页复杂图表/大图片整本导出；本地 Windows 打包成功不代表远程 Actions 或其他平台实机通过。每批记录代码、交互、导出报告与实际应用测试，无法实测的部分明确保留未验证状态。
