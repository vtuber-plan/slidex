# 1.7.0-rc.2 工作区交互修复

## 启动目录

本轮 Windows x64 解压版：`release/1.7.0-rc.2/win-unpacked/SlideX.exe`。

实查归档中的版本和前端资源：旧 `release/win-unpacked` 为 1.6.1，正文编辑使用弹窗；`release/1.7.0-rc.1/win-unpacked` 为 1.7.0-rc.1，已在原文本框内挂载编辑组件。旧目录未删除或覆盖。

## 修复

- 左侧幻灯片栏和右侧属性栏之间的分隔条支持拖动调宽；展开备注后拖动其上方分隔条调整高度。支持方向键、Home/End，尺寸本地保存，并限制最小画布空间。
- 桌面应用内文件菜单不再调用 Electron 不支持的 `prompt()`，改用系统文件选择器；浏览器入口使用路径输入对话框，以保留原文档所在目录及相对资源引用。
- 桌面原生菜单与应用内文件菜单共用打开事务：提交原位文字、保存未保存修改、验证目标文档后切换。取消、读取失败或无效文件不切换；更新桌面标题与最近文档。
- 框内文字编辑保持原位，不打开正文模态框；新增实际打包程序的检查。

## 验证

`test/react-workspace.mjs` 覆盖原位编辑、三处拖动、尺寸持久化、文件选择取消/错误/成功、旧文件修改保留及浏览器路径对话框。

`test/workspace-electron.cjs` 使用真实 Electron 主进程，替换文件选择器返回值后验证原生菜单、系统选择器接线、窗口标题与取消行为；不声称自动点击了系统选择器界面。

用户反馈手动输入无问题；具体使用目录可能对应旧版，记录见 `text-editing-qa.md`。

本轮生产构建、工作区专项及 Electron 原生菜单专项通过；实际解压程序的框内编辑、保存及 HTML/PNG/PDF/PPTX 导出断言通过。完整回归运行中 React 编辑器与组合套件达到 240 秒超时，未将本轮完整回归标记为通过。旧界面的动画检查原先跨两次浏览器调用读取 300 毫秒动画，负载下会错过动画；改为同一次调用触发并检查，独立复测通过。
