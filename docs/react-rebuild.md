# React 编辑器重构

基线：`b29f97b`（1.6.1，47 项测试通过）。

## 目标与边界

将正式编辑入口迁移到 React，建立可扩展的组件、文档事务和共享播放内核。XML DSL、IR、序列化、服务端和导出继续作为独立核心。历史界面仅用于迁移期回归参考，不作为新界面的运行依赖。

技术栈：React / TypeScript / Vite；Tailwind CSS + Radix Themes；Zustand 文档状态；ProseMirror 富文本。自定义 SlideSurface、Canvas、Inspector、Filmstrip、AnimationPanel、Player 和 Presenter 组件。

## 实施与验收顺序

1. 工程和状态：构建静态资源；单一文档状态；撤销重做、选区、事务、保存状态、错误呈现；服务端和 Electron 路由兼容。
2. 编辑器：可访问的菜单/弹窗/工具栏；缩略图排序；画布拖拽、缩放、框选、多选、吸附、缩放手柄；图层、对齐、组合、锁定；主题和母版；源码和诊断。
3. 内容：ProseMirror 选区格式、列表、链接、字体、颜色、撤销和中文输入；表格与图表数据面板；图片上传与裁剪；形状和图标浏览；动画排序和预览。
4. 播放：同一播放内核用于 React Player 与 HTML 导出；可中断动画、点击组、切页清理、缩略图导航；演讲者当前页/下一页/备注/计时；预览网格与嵌入入口。
5. 验证：核心回归、生产构建、浏览器真实操作、保存后重载、撤销重做、动画/HTML 一致性、桌面资源打包。

每一步均须实际接线，不能用静态按钮或旧界面嵌套代替实现。缺失功能或测试限制必须记录。

## 后续产品能力

大规模形状库、更多图表类型、运动路径、云端版本历史和协作分享是独立增量，不把框架迁移等同于这些功能已完成。

## 框架迁移交付状态

- 工程、状态、正式 React 入口、结构化内容面板和共享 Player 已落地。独立 Viewer 分包，不加载 ProseMirror。
- 新增串行自动保存、HTTP 409 外部修改保护、最近 20 次本地保存历史、搜索替换、格式复制、等距分布和桌面编辑命令桥。
- React 内的公式、图标和对应字体作为本地资源打包；修复深色播放器影响默认单元格文字颜色的问题。
- 验收：完整测试 48 项通过，其中 React 浏览器套件包含 42 个独立断言；隐藏 Electron 加载 6 页和保存通过；Windows x64 解包构建通过。

## 明确的剩余边界

- 保留 `/legacy` 兼容入口，正式入口不依赖旧 UI。React 常规界面支持中英文即时切换；部分服务端/DSL 诊断原文及低频技术枚举仍待本地化。
- 文本现已在实际画布文本节点内使用 ProseMirror 编辑；真实操作系统中文 IME、复杂混排与极端溢出排版仍需专项人工验收。
- 表格支持跨合并区域增删单行/单列，暂不提供选区批量删除。图片支持八个手柄裁剪和内部平移，暂不提供裁剪纵横比预设。
- 图表仍为 5 类、内置形状为 9 类加自定义路径、动画仍为 9 种。组件化和可视化编辑已提升，类型扩展是下一阶段。
- 母版、字体、复杂渐变等低频高级属性部分使用结构化设置；团队协作与云端分享不在本轮。
- Windows x64 已验证；macOS、Linux 和 Windows ARM 安装包未在本机运行验证。

### 文本编辑专项进度

- 组合输入开始/结束设置文字历史边界，连续两次输入可分别撤销。提交先结束焦点输入，并读取最新 DOM，避免观察器尚未处理最后输入时保存漏字；忽略光标辅助节点，保证仅打开关闭不会重写文档。
- 新增段落对齐、行距（倍数/px）、段前/段后间距及列表缩进/减少缩进入口。共享渲染保留段后间距、有序列表起点和连续空格；原位编辑继承自动换行设置，移除不合理的最小高度。
- 选中文字或把光标放入已有链接后，可修改/移除链接。公式提供插入、选中后修改、实时预览、语法校验及删除入口，保留 DSL 行内公式表达。
- 粘贴时过滤网页样式/脚本节点并保留 div 段落边界；规范不换行空格实体和链接查询参数转义。Shift+Enter 插入软换行，不拆分段落。
- 对选中文字测量局部布局，超出文本框时提示裁切；旋转与缩放不影响检测。提示不会自动改变字号或文本框尺寸。
