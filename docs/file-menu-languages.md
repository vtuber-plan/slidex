# 文件菜单与界面语言

2026-09-21 源码更新，尚未生成新的桌面发布包。

此前原生桌面菜单与 React 文件菜单分别维护。原生菜单默认隐藏，界面菜单又没有新建、另存为入口，导致常用操作难以发现。本次把新建和另存为接入统一的文档操作流程。

## 文件操作

文件菜单提供新建、打开、保存、另存为、下载 XML、导出和偏好设置。桌面快捷键为 Ctrl/Cmd+N、O、S、Shift+S。浏览器可能保留新窗口/打开文件快捷键，菜单点击入口始终可用。

- 桌面新建/另存为使用原生路径选择窗口；浏览器模式输入完整本地路径，路径由本地服务处理。
- 新建前提交原位文字并保存当前未保存的修改；保存失败则不切换文档。取消路径选择不创建文件。
- 另存为保留原文件，创建新文档并切换到它。目标已存在时拒绝覆盖，请换一个名字；编辑当前文件应使用“保存”。
- 同目录另存保留媒体相对路径；跨目录另存将本地图片与字体样式、样式中的字体 URL 内嵌到 XML。远程资源仍使用原地址。多文件项目另存为合并后的单文件，ID 与动画引用保留。
- 缺失/越界资源、循环引用及含 `@import` 的字体 CSS 会中止跨目录另存，不生成残缺文档；内嵌后超过 30MiB 也会中止。可先整理资源，或另存到原目录。资源内嵌会增加 XML 大小。
- 新文件先写入同目录临时文件，再以不覆盖目标的方式发布；原文档和已有目标文件不会被覆盖。

## 语言

偏好设置现在提供简体中文、English、日本語（预览）和 Español（预览）。日语和西班牙语首批覆盖文件/编辑菜单、偏好设置、常见属性、放映及源码工具；未覆盖的条目使用既有英文翻译，部分动态诊断仍可能保留原始语言。不是完整本地化版本。

语言元数据和新增词典位于 `src/locales.ts`，React、服务端偏好校验与 Electron 原生菜单共享。切换无需重载；桌面菜单通过既有语言同步机制更新；偏好持久化与端口无关。文档内容和 DSL 不随界面语言转换。
