# SlideX 修复与补全计划

## 原则

- 先保证 `.slx` 语言、解析、校验、序列化和渲染的一致性，再修改编辑器。
- 先修复数据丢失、崩溃和导出错误，再补交互便利功能。
- 每个阶段必须增加回归测试，并通过 `npm test`。

## Phase 1：DSL 与核心管线

- [x] 空 `<chart/>` 不得导致解析器崩溃。
- [x] 缺省元素/页面 id 按规范自动生成，且避开已有 id。
- [x] 空 deck 给出明确诊断，并生成可供编辑器恢复的空白页。
- [x] 补齐 chart 数据列数、列名唯一性和 table span 越界校验。
- [x] 补齐 opacity、crop、枚举、布尔值等属性校验。
- [x] 补齐背景、渐变、表格主题等 `$ref` 校验。
- [x] 为非法富文本样式产生 `W_STYLE_PROP`。
- [x] 修复 shape 图片填充的相对媒体路径。
- [x] 修复独立 HTML 的转义、自包含声明与路径安全问题。
- [x] 为以上行为增加异常输入回归测试。

## Phase 2：编辑器正确性

- [x] 导出前把当前内存 deck 保存或直接传给导出端，避免导出旧文件。
- [x] 修复检查器富文本/备注的 HTML 转义顺序。
- [x] 统一所有操作的“修改前快照”，修复源码、格式刷、颜色和动画撤销。
- [x] 编辑后重新运行语义校验，避免状态栏诊断过期。
- [x] 保留 `ul/ol/li`，修复内联编辑列表损坏。
- [x] 修复演讲者视图不可见和自定义字体未加载。
- [x] 实现 `afterPrevious` 自动串联，并保留元素 rotation/flip。
- [x] 缩放 line 时同步缩放局部 points。
- [x] “格式化源码”解析并格式化输入框内容，不覆盖未应用修改。
- [x] 避免表格/图表检查器无提示丢弃高级属性。

## Phase 3：编辑器能力补全

- [x] 缩略图拖拽排序（页面批量操作待补）。
- [x] 水平/垂直等间距分布和智能参考线（可选网格留待后续）。
- [x] 元素分组/解组、锁定、旋转手柄和宽高比控制。
- [x] 图片文件选择、复制到 media、四边裁剪界面。
- [x] 动画方向、延迟、排序和单项预览（完整时间线留待后续）。
- [x] 母版、主题、调色板、文本样式和 deck 属性面板。
- [x] 表格行列编辑及完整图表系列/坐标轴表单（可视化单元格合并留待后续）。
- [x] 搜索替换、自动保存和崩溃恢复。
