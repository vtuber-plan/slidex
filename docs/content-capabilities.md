# 第三批：内容能力与导出子集

2026-09-20。源码实现，尚未生成新的桌面发布包。保留现有 React、共享渲染器和播放器；没有引入跨组重组或双轴图表。

## C1 形状库

36 种内置预设，另外支持 `custom` 路径。基本图形、箭头、星形、标注和流程图共用 `src/shape-library.ts` 注册表。插入工具栏打开形状库，可按分类及中英文名称搜索。切换形状时清除上一形状的调整参数，避免把圆角半径误用为比例。

新增预设：`rightTriangle`、`parallelogram`、`trapezoid`、`pentagon`、`hexagon`、`heptagon`、`octagon`、`decagon`、`dodecagon`、`leftArrow`、`upArrow`、`downArrow`、`leftRightArrow`、`upDownArrow`、`homePlate`、`star4/6/8/10/12`、`plus`、`callout`、`flowProcess/Decision/Input/Document/Terminator`。

可调形状选中后出现黄色控制点，拖动可改变主参数，复用现有组内坐标、旋转、翻转与撤销机制。右侧“形状参数”可精确输入，参数如下；右箭头第二参数仍可在高级属性中输入。

控制点获得焦点后可用方向键微调；比例步长 0.01，圆角步长 1px，Shift 放大为十倍。

| 形状 | `adj` 与范围 |
| --- | --- |
| roundRect | 圆角 px，默认 8；非负，绘制时上限为短边的一半 |
| triangle | 顶点横向比例，0～1，默认 0.5 |
| rightArrow | 杆宽比例、头长比例，0.05～1，默认各 0.5 |
| left/up/down/leftRight/upDownArrow | 杆宽比例，0.05～0.95，默认 0.5 |
| parallelogram / trapezoid | 斜边比例，0～0.45，默认 0.2 |
| chevron / homePlate | 箭头深度，0.05～0.95，默认 0.5 / 0.25 |
| donut | 环宽比例，0.02～0.95，默认 0.25 |
| star4/5/6/8/10/12 | 内外半径比例，0.05～0.95，默认 0.382 |
| plus | 横竖厚度比例，0.05～0.95，默认 0.3 |
| callout | 尖角横向位置，0.1～0.8，默认 0.3 |

参数数量、有限数值和范围由 DSL 检查，非法参数报 `E_SHAPE_ADJ`。五角星保留旧版按短边绘制的外观；新增星形按对象宽高拉伸。

PPTX 中，多边形预设使用与 SVG 相同的顶点写入原生自由形状，保留编辑能力。矩形、圆角矩形、椭圆、菱形使用原生预设。圆环、五角星及曲线流程图等尚未精确映射的几何使用图片回退并进入报告。原生自由形状在 PowerPoint 中不保留 SlideX 的参数控制点，可编辑其几何顶点或在源文档调整参数。

## C2 图表

新增雷达、气泡、瀑布图，均通过共享 SVG 渲染进入编辑器、Viewer 和保真导出。右侧图表面板可切换类型和数据映射；气泡图额外提供 Size 列。

| 类型 | 数据语义与限制 |
| --- | --- |
| radar | x 为类别，y 为非负数，至少三行；多系列使用同一径向范围。空值形成断点，不补零；不与其他类型混用 |
| bubble | x/y 为有限数值，允许负数；size 为非负数值列，圆面积与 size 成比例。size 为零、空值或坐标缺失时不绘制；不与其他类型混用 |
| waterfall | 单系列，x 为类别，y 为带正负号的增量；从零累计，负值用红色，空值跳过且不改变累计值。没有隐式总计行，不支持堆叠 |

空字段与 `null` 均表示缺失值；数据面板清空单元格也使用相同语义。普通折线/面积图跳过缺失点并连接剩余有效点；雷达图在缺失处断开。数值类别仍按类别排列，不再重叠在同一位置。雷达/瀑布当前使用自动刻度，不接受额外轴样式；数值轴的非有限边界、min ≥ max 会产生诊断。双轴绑定明确报 `E_CHART_AXIS`，不隐式忽略。

PPTX 原生子集：同类、非堆叠的 bar / line / area / pie / scatter，保留系列、类别、数值、标题、图例与内嵌 XLSX 数据。混合系列、复杂轴样式、平滑线、数据标签、环形饼图、特殊变换等超出子集的情况仍按图表对象回退。三种新类型本批也使用图片回退。原生图表由 PowerPoint 排版，轴线、字号、间距等可能与 SVG 不同；需要视觉保真时使用图片模式。

后续顺序：先扩展原生图表的轴样式、标签及堆叠；然后单独设计双轴及系列绑定；热力图（矩阵与色标）、树图/旭日图（层级及聚合）、桑基图（节点边及守恒）、蜡烛图（OHLC 与时间轴）分别定义数据协议后分批实现。

## C3 动画

新增 `spin`、`color`、`fly-out`、`zoom-out`、`wipe-out`、`motion-path`，复用同一个 Viewer/HTML 播放内核。

- `spin`：`angle` 为相对旋转角，默认 360，范围 ±36000 度；完成后保留该角度。
- `color`：`color="#RRGGBB"`，对文字颜色和 SVG 填充做一次强调，动画中点达到目标颜色，结束恢复原色；图片像素不参与颜色替换。
- `motion-path`：`path="0,0 100,30 160,0"`，2～1000 个相对位移点，必须从 0,0 开始。坐标在对象父容器的局部坐标系中，正 x 向右、正 y 向下；线性分段路径，最终停在末点。每个坐标绝对值不超过 100000。
- 新退出效果结束后保持退出外观。切页、返回、重播或关闭预览取消动画，恢复文档原始变换，避免残留。
- 顺序执行的变换从当前视觉变换继续；同一对象同时播放修改相同属性的动画时，后启动者覆盖该属性，不做多轨加法混合。

右侧动画面板提供路径坐标、旋转角度、颜色编辑，以及可视化时间线。条带表示最早执行时刻和持续时间，单击跳到对应编辑卡片；触发、时长、延迟仍在卡片编辑。时间线中的点击步骤不代表实际用户点击间隔。本批不是可拖拽多轨关键帧编辑器。

动画 duration/delay 为 0～600000ms，未指定 duration 默认 500ms；零时长保留，播放按至少 1ms 执行。路径、方向、颜色、角度和时间非法时有 DSL 错误，不通过保存/导出校验。

PPTX 首批支持原生顶层对象的 `onClick` 触发 `appear / disappear / fade-in / fade-out`；支持 fade、slide-left、slide-up、zoom 页面切换。嵌套对象、组合、栅格化对象、自动/并行动画和新复杂效果暂不映射，在能力报告中明确列出。省略的效果不会自动转换为另一个效果。

PNG/PDF 和整页图片 PPTX 使用文档静态布局：入场可见，不执行强调、路径和退出；不会把预览中停留的变换带入导出。
