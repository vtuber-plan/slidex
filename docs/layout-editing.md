# 页面、图层与布局编辑

2026-09-20：第二批源码实现。尚未生成新的桌面发布包，已有 rc.6 不包含这些功能。

## 页面管理

- 左侧单击切换当前页；Ctrl（macOS 为 Command）切换选择，Shift 从锚点选择连续范围。当前页始终属于所选页，不能通过 Ctrl 取消最后一个选中页。
- 底部复制、删除作用于所有所选页；拖动其中一页可整体移动。上移/下移保持所选页面的相对顺序，把所选页作为连续块整理。
- 页面列表获得焦点时，Ctrl+A 全选页面，Ctrl+D 复制，Delete/Backspace 删除；上下方向键切页，Shift+方向键扩选，Ctrl+Shift+方向键移动。
- 每次批量操作只生成一次撤销记录。删除全部页面后保留一张新空白页；撤销可恢复原文档。页面选区为编辑器状态，不写入文档。

复制页放在最后一个所选页之后。复制出的页面和所有嵌套对象生成无冲突 ID，动画目标同步更新；指向同批复制页的 `href="slide:…"` 改指向新副本，指向未复制页的链接保持原目标。其他页面指向原页的链接不变。母版仍引用原母版。删除页面时清除文档中指向被删页面的对象链接，撤销同时恢复链接。

## 层级图层树

右侧“图层”显示完整的当前页面或母版层级，顺序对应从上到下的视觉层叠。展开组合后单击子元素可进入对应组内并定位；同一父级支持 Ctrl 多选。拖动调整同级顺序，不支持跨组拖动或复杂重组。

重命名按钮、名称双击或 F2 修改 `label`，保留 `id` 和动画目标。上下方向键浏览行，左右方向键展开、收起或返回父级，Enter 选择。眼睛按钮切换 `hidden`，锁按钮切换 `locked`。父组锁定时，后代的改名、显隐、锁定和排序操作均禁用；先解锁父组才能修改后代。

隐藏属于文档语义：隐藏对象及其后代在编辑画布、缩略图、Viewer、HTML 和 PNG/PDF/PPTX 中均不绘制，动画播放跳过隐藏目标。隐藏只改变显示，不删除内容，图层树仍可找到对象并恢复。单纯隐藏参考线则属于用户偏好，不隐藏任何文档内容。

## 标尺、参考线和网格

顶部“视图”集中开关标尺、参考线、网格和吸附。“参考线与网格…”提供数字输入、添加居中参考线及删除入口，可用键盘操作。没有新增占用画布空间的工具栏。

从水平标尺向画布拖动创建横线，从垂直标尺拖动创建竖线。拖动已有参考线调整位置，拖出画幅删除；Esc 取消当前拖动。参考线获得焦点后，方向键微调 1px，Shift 微调 10px，Delete 删除。一次拖动对应一次撤销。

- 固定参考线存入当前页面或母版的 `guides-x` / `guides-y`，以页面坐标为单位，随保存重载保留；不出现在 Viewer 或导出中。
- 网格间距（2～200px）、标尺/网格/参考线开关和吸附开关属于用户偏好，保存在浏览器本地；桌面还通过偏好文件在服务端口变化后恢复。
- 移动和缩放吸附到固定参考线；网格启用后参与吸附。移动时参考线对齐对象包围框边缘或中心，网格对齐左上角；组合坐标先转换为页面坐标再计算修正。
- 吸附阈值为 5 个屏幕像素，随缩放换算；Alt 临时关闭吸附。隐藏参考线不参与吸附。

## 验证与边界

新增 `test/layout-operations.mjs` 和 `test/react-layout.mjs`，纳入 `npm test`：覆盖批量 ID/动画/跨页链接、删除全部页面、撤销、嵌套图层改名与父锁保护、显隐、DSL 重载、参考线拖动和撤销、偏好跨端口恢复、Viewer 与原生 PPTX 排除隐藏对象。

浏览器交互检查 50%、100%、200% 下实际鼠标移动吸附，以及参考线键盘微调；几何测试覆盖嵌套旋转、水平/垂直翻转后的对象包围框吸附和网格定位。既有组内编辑、文本、菜单、导出等回归一并运行。界面截图检查了标尺不改变画布大小和图层显示；Electron 工作区测试覆盖原生菜单、偏好设置、文件选择及导出取消。

本次结果：构建通过；完整 `npm test` 首跑 63 项通过，菜单测试因系统分配的随机端口 6669 被 Chrome 禁止访问而失败，单独复跑该项通过；最终调整后重跑布局交互及几何专项通过。`npx electron test/workspace-electron.cjs` 通过。随机端口问题仍是测试环境的偶发风险，本批未修改服务端口分配策略。

这批没有增加跨组拖拽、复杂重组、独立页面整理窗口，也没有扩展 PPTX 动画能力。导出仍遵循 [既有保真边界](export-reliability.md)，不承诺跨渲染引擎像素完全一致。
