# 文本编辑验收（2026-09-19）

## 自动验证范围

`test/react-text.mjs` 使用 Chromium 的组合输入协议验证 preedit 更新、确认、连续输入、整次撤销/重做，以及组合输入中保存、切页、点击外部。另覆盖未被编辑器观察器处理的最后一次 DOM 更新，防止提交时漏字。

这些测试不启动 Windows 输入法，不证明真实候选窗选词、切换中英文及候选窗位置正确。当前自动化环境没有原生桌面输入控制，以下人工验收尚未执行。

## Windows 原生输入法待验收

在 Windows Electron 应用和 Chrome 中分别执行；记录 Windows、输入法、浏览器/应用版本及结果。

1. 使用微软拼音在普通文本框输入 `zhongwen shuru`，通过空格、数字键和鼠标选择候选词；每种方式都应只提交一次，无漏字、重复或残留拼音。
2. 连续输入两组中文，Ctrl+Z 应按两次组合输入分别撤销，Ctrl+Y 完整恢复。候选尚未确认时按 Enter/Esc，应优先由输入法确认/取消候选，不提前结束文本编辑。
3. 候选窗打开时点击画布空白处、切换页面、点击保存，分别检查最后一次输入是否保留。返回页面、保存重载后内容应一致。
4. 在候选窗打开时切换中英文，输入中文、英文、标点和 emoji；验证光标位置及删除行为。
5. 对旋转文本、双层旋转/翻转组合里的文本，分别在适应画布及放大后重复输入；检查候选窗是否跟随光标，输入期间不跳位。
6. 在长文本、列表项及公式前后输入，检查换行、输入法候选确认和 Enter 新建段落不会互相干扰。

失败时记录操作序列、预期/实际文本、截图和可复现的最小 `.slx`；不要用自动化组合输入测试通过来替代此项签收。
