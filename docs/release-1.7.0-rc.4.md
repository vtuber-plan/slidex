# 1.7.0-rc.4 画布导航与工作区

## 使用

- 空格加鼠标左键拖动，或鼠标中键拖动：平移画布。Esc 回到本次拖动前的位置；失焦或指针取消时不会保留拖动状态。
- 普通滚轮平移，Shift+滚轮横向平移；Ctrl/Command+滚轮围绕鼠标位置缩放。
- 底部可输入 10–400% 比例；100% 对应文档尺寸的 1:1 CSS 像素。适应画布会重新居中并随面板／窗口尺寸更新，手动缩放则保持实际比例。
- 顶部排列工具栏右侧提供左右面板折叠按钮，折叠状态及已有尺寸分别记忆。备注继续通过其标题展开／收起。
- 文字编辑保留设计／图层／动画标签。切换标签先提交文字，重新编辑文字回到设计标签。用户已折叠的属性栏不会因进入文字编辑而强制展开。

导航状态独立于 DSL 和撤销历史。组内对象继续通过画布缩放与祖先变换的逆矩阵定位；对象拖动期间不接受额外的滚轮缩放。输入文字时空格仍是正常字符，输入框、按钮和菜单不拦截为空格平移。
